## Three steps to your next set

1. **Install the extension.** Choose Chrome or Edge above, or download the [latest ZIP](https://github.com/BlackiePiggy/DJ-Set-Tracker/releases/latest).
2. **Put on a set.** Open a YouTube or Bilibili video in your desktop browser and click **SET TRACKER** on the right.
3. **Choose a tracklist.** Use an available version, or open **Import / Sources** to bring in a source. Check the tracks and cues, then press play.

Installing from a ZIP? Extract it first, enable Developer mode on your browser’s extensions page, then choose **Load unpacked**. [Full installation and update guide →](docs/GETTING-STARTED.md)

## Choose your update channel

| Channel | Best for | How updates arrive |
| :--- | :--- | :--- |
| [Chrome Web Store](https://chromewebstore.google.com/detail/set-tracker/jdpgcgcbigjpgfheaimikbkmgdpkaaod) / [Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/set-tracker/dicipdfdgkemhcflmngpgojnhoialnoj) | Everyday use | The browser distributes approved store updates on its own schedule |
| [GitHub Releases](https://github.com/BlackiePiggy/DJ-Set-Tracker/releases/latest) | Manual access to the latest package published here | Download the ZIP, update the original installation folder and reload the extension |

GitHub releases begin with **v0.31.17**. Store review and GitHub publishing are independent, so version numbers can differ. ZIP installations do not auto-update through GitHub.

For new-release notifications, choose **Watch → Custom → Releases** at the top of this repository. Download **DJ-Set-Tracker-Chrome-Edge.zip** from the release assets. GitHub’s automatic “Source code” archives contain this promotional repository and are not installable extensions.

## Help, privacy & the small print

Built for desktop Chrome and Edge on YouTube and Bilibili. Tracklists come from available data and sources you choose; this is not background audio recognition. Coverage and cue accuracy vary by video.
