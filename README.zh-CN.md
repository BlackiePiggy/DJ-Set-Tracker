## 三步开始

1. **安装插件。** 选择上方 Chrome / Edge 商店，或下载 [最新 ZIP](https://github.com/BlackiePiggy/DJ-Set-Tracker/releases/latest)。
2. **打开一场 Set。** 在桌面浏览器打开 YouTube 或 Bilibili 视频，点击右侧的 **SET TRACKER**。
3. **选一份曲目表。** 使用已有版本，或从 **Import / Sources** 导入来源；检查曲目和时间后开始听。

ZIP 安装需要先解压，再在浏览器扩展管理页启用开发者模式，点击“加载已解压的扩展程序”。[查看完整安装与更新说明 →](docs/GETTING-STARTED.zh-CN.md)

| 渠道 | 适合谁 | 更新方式 |

| [Chrome 商店](https://chromewebstore.google.com/detail/set-tracker/jdpgcgcbigjpgfheaimikbkmgdpkaaod) / [Edge 商店](https://microsoftedge.microsoft.com/addons/detail/set-tracker/dicipdfdgkemhcflmngpgojnhoialnoj) | 希望日常使用省心 | 商店版本获批后，由浏览器按其更新机制分发 |

GitHub 发布从 **v0.31.17** 开始。商店审核与 GitHub 发布相互独立，版本号可能不同。ZIP 不会通过 GitHub 自动更新到浏览器。

需要更新提醒：在仓库右上角选择 **Watch → Custom → Releases**。请下载 Release 附件中的 **DJ-Set-Tracker-Chrome-Edge.zip**；GitHub 自动生成的 “Source code” 压缩包只包含这个宣传仓库，不能安装为插件。

## 支持与隐私

支持桌面版 Chrome 和 Edge，视频平台为 YouTube、Bilibili。曲目表来自已有数据和用户选择的来源，不是后台听音识曲；来源覆盖和时间准确性因视频而异。
